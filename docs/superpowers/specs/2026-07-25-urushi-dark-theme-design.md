# 黑漆主題與研出效果

日期:2026-07-25

## 目標

讓網站「更華麗」,但華麗必須來自漆器本身的材料語彙,不是通用網頁裝飾。

## 出發點與張力

現況是刻意的極簡白底畫廊風,`global.css` 開頭寫著「留白為主,作品說話。少色、少線、少動效」。使用者要求增加特效與華麗度,方向與原設計相反 —— 這點已向使用者說明,使用者確認要做。

設計指引警告「近黑底 + 單一亮色點綴」是 AI 生成設計的三大預設之一。底色方向由使用者指定,不更改;但**執行方式**必須取材於漆藝,避免變成通用深色模式。

## 使用者決策

| 項目 | 決定 |
|---|---|
| 華麗方向 | 材質質感 + 動態效果 + 圖片展示強化(**不含**版面裝飾) |
| 底色 | 黑漆底 + 金 |
| 動效強度 | 中等 —— 明顯但不吵鬧 |
| 螺鈿虹光 | **砍掉**(最容易變俗) |
| 拉丁字體 | 換成 Cormorant Garamond |

## 核心概念:研出 (togidashi)

研出蒔繪的工序是把金粉埋進漆層裡,再一層層把表面的黑研磨掉,讓圖像從黑裡浮出來 —— 不是加上去,是磨出來的。

所有進場動畫改用這個邏輯:一道柔和遮罩由下往上把黑「磨開」,金線先浮現、再是內容。取代現有的「淡入 + 上移 14px」。

節奏刻意放慢(約 1.2s),呼應作品說明裡「漆需要濕度與等待才會硬化」。

## 實作範圍

### 1. 色票(`global.css` `:root`)

原先設想把 `--paper` 改成文字色,但那會讓每一處 `var(--paper)` / `var(--ink)` 的語意反轉,全檔數十個使用點都要人工改寫,風險高且沒有好處。

改用的作法:**材料色票另立新名,語意角色沿用原有名稱、只換值**。`--ink`(主文字)/ `--paper`(背景)這組比喻在深色主題下仍然成立 —— 漆面是「紙」,淺色字是「墨」。使用點零改動。

```css
/* 材料色票 */
--urushi: #14100d;       /* 黑漆 */
--urushi-deep: #0c0908;  /* 研出的凹處 */
--togidashi: #1e1915;    /* 次層面 */
--gold: #c9a961;         /* 金粉 */
--gold-dim: #8a7440;     /* 沉下去的金 */

/* 語意角色(名稱不變,值改為深色主題) */
--paper: var(--urushi);         /* 背景 */
--paper-deep: var(--togidashi); /* 次層背景 */
--ink: #e9e3d7;                 /* 主文字 */
--ink-soft: #9a9184;            /* 次要文字 */
--rule: #2c2620;                /* 結構性分隔線 */
```

唯一需要改名的是 `--vermilion` → `--gold`(3 個使用點),因為「朱紅」這個名稱在值變成金色後會誤導。

實測對比度(對 `--urushi` 背景):主文字 14.81:1、次要文字 6.09:1、金 8.41:1,皆過 AA。
`--gold-dim` 只有 4.19:1,因此**限定用於裝飾漸層,不可當文字色**。
`::selection` 須用 `--gold` 當底配 `--urushi` 文字(8.41:1);用 `--gold-dim` 當底只有 3.53:1,不到 AA。

### 2. 字體

- 中文標題維持 **Noto Serif TC**(換字體有繁體缺字風險)
- 拉丁標題與品牌名改用 **Cormorant Garamond 300**(高對比襯線,細筆畫在黑底上像漆面反光)
- 內文與標籤維持 **Noto Sans TC**

字體堆疊順序須讓 Cormorant 在前、Noto Serif TC 在後,由瀏覽器對拉丁字元用 Cormorant、中文字元 fallback 到 Noto Serif TC。

Cormorant 的 x-height 偏小,套用後 `.brand` 與首頁 `h1` 沿用原字級會顯得比原本輕。兩處須略微加大以維持原有視覺重量(`.brand` 1.15rem → 1.5rem、`h1` 上限 2.1rem → 2.6rem)。**這是補償字體換用,不是改成大型標題**;使用者未選版面裝飾,不得藉此放大成主視覺。

### 3. 研出 reveal

- CSS:`mask-image` 線性漸層 + 動畫 `mask-position`,由下往上磨開;同時 `opacity` 0 → 1
- 觸發:IntersectionObserver,滾到視窗內才播,播完 `unobserve`
- 類別命名由 `.rise` / `.rise-2` / `.rise-3` 改為 `.togidashi` / `.togidashi-2` / `.togidashi-3`(共 11 處使用,分布於 7 個 view)

**無 JS 時內容必須仍可見。** 作法:head 內嵌腳本為 `<html>` 加上 `.js`,CSS 的隱藏初始狀態限定在 `.js .togidashi` 之下。JS 失效時內容直接顯示。

**View Transitions 相容:** 須在 `astro:page-load` 重新初始化,否則換頁後 observer 失效、內容永久隱藏。

### 4. 金線

- 結構性分隔線用暗色 `--rule`
- 重點處(page-head 下、hero 標題下、年份分組標題下)用金色漸層(兩端透明)
- 滾到時 `transform: scaleX(0 → 1)` 由左展開

### 5. 黑漆深度

`body` 疊一層極淡 `radial-gradient`,模擬漆面反光,避免死平的純黑。

### 6. 作品圖光暈與金框

- 圖外圈柔和 `box-shadow` + 極細金框
- 解決實際問題:`tung-cat-01/02` 是白底/銀底照片,在黑底上會像貼上去的亮方塊,細金框讓它落進頁面
- hover:輕微上浮 + 光暈增強 + 金框變亮

### 7. Lightbox(點擊放大看圖)

- 原生 `<dialog>` + `showModal()`,自帶 focus trap 與 Esc 關閉
- 套用位置:作品詳細頁 gallery(首頁 hero 與作品卡都是連結,不攔截點擊)
- 深色 backdrop
- 關閉按鈕文字須雙語,新增 i18n 鍵 `lightbox.close`

## 硬性約束(不可違反)

1. **照片比例一律不變** —— 沿用前次需求。
2. **不對作品圖套任何 `filter`** —— 不為了配深色主題壓暗作品。
3. **縮圖 hover 不做放大推近** —— 該效果需 `overflow: hidden` + `scale`,會裁掉照片邊緣。改用上浮 + 光暈 + 金框代替。
4. **版面結構不動** —— 使用者未選版面裝飾,不加紋樣背景、邊框裝飾、大型標題。
5. **`prefers-reduced-motion`** —— 所有研出直接顯示為完成狀態,金線不展開,lightbox 保留但無動畫。
6. **無外部 library** —— 純原生 CSS + 一支小 JS。

## 驗收條件

- `npm run build` 成功。
- 所有作品圖 intrinsic 尺寸仍等於原檔(1815×902 / 1567×1045 / 1108×1477)。
- 建置後 CSS 不含任何作用於作品圖的 `filter`。
- 停用 JS 時所有頁面內容仍可見(檢查 `.js` 前綴是否正確限定隱藏狀態)。
- 換頁(View Transitions)後研出效果仍正常,內容不會永久隱藏。
- 文字對比度達 WCAG AA。
- Lightbox 可用鍵盤操作:Enter/Space 開啟、Esc 關閉、focus 回到觸發元素。
- 手機寬度下版面不變形。
